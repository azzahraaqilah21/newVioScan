# ============================================================================
# BC-Care Raspberry Pi 4 — Python Dependencies (Runtime)
#
# Target : Raspberry Pi OS 64-bit (aarch64) — Bullseye (Python 3.9/3.10)
#          ATAU Bookworm/Trixie (Python 3.11/3.13).
#          bccare_db.py memakai sintaks `dict | None` yang dievaluasi saat
#          import → Python >= 3.10 WAJIB (3.9 gagal).
#
# Cara pasang tercepat:
#   bash install.sh
#   (atau ikuti langkah manual di bawah)
#
# LANGKAH MANUAL
# ── 1. Prasyarat sistem (APT — beberapa paket TIDAK tersedia via pip) ────────
#   sudo apt update && sudo apt install -y \
#       python3-venv python3-dev \
#       python3-numpy python3-pil \
#       python3-rpi.gpio \
#       python3-picamera2 python3-libcamera \
#       libbluetooth-dev bluez pi-bluetooth
#
#     • python3-picamera2 : driver kamera. WAJIB via apt — versi pip butuh
#       binding libcamera yang tidak ada di PyPI.
#     • python3-rpi.gpio  : GPIO (LED iluminasi/indikator, HC-SR04, tombol).
#     • libbluetooth-dev  : header C agar PyBluez bisa di-compile.
#     • pi-bluetooth+bluez: stack Bluetooth Classic (SPP/RFCOMM).
#
# ── 2. Virtual environment yang tetap melihat paket apt ─────────────────────
#   python3 -m venv --system-site-packages ~/bccare_venv
#   source ~/bccare_venv/bin/activate
#   pip install -r requirements.txt
#
# ── 3. Kamera & layanan Bluetooth ───────────────────────────────────────────
#   sudo raspi-config nonint do_camera 0
#   sudo systemctl enable --now bluetooth
#
# ── 4. Paket perangkat keras (best-effort — jalankan terpisah agar kegagalannya
#       tidak menggagalkan instalasi utama di atas) ──────────────────────────
#   pip install PyBluez                  # SPP + registrasi SDP (disarankan)
#   python3 -c "import RPi.GPIO" 2>/dev/null || pip install RPi.GPIO
#                                        # fallback apt sudah via --system-site-packages
#   # Jika RPi.GPIO gagal build di Python 3.13:
#   #   pip install rpi-lgpio            # shim API-compatible
#
# CATATAN PENTING
#   • PyBluez mendaftarkan service SPP ke SDP agar flutter_bluetooth_serial di
#     Android bisa menemukan & konek. Fallback native AF_BLUETOOTH (tanpa
#     PyBluez) TIDAK mendaftar SDP → pairing manual lalu konek by-address.
#   • Python 3.13 (Trixie): tidak ada wheel tflite-runtime → pakai LiteRT
#     (ai-edge-litert, ~30 MB) yang memuat .tflite. TensorFlow penuh
#     (~500 MB+) TIDAK dipasang: disk sistem Pi sempit, dan .keras memang
#     tidak dipakai untuk inferensi (lihat poin berikut).
#   • Jangan deploy file model .keras ke Pi — pakai .tflite hasil
#     export_to_tflite.py (jalankan di PC, lihat requirements-dev.txt).
# ============================================================================

# ── Dasar ────────────────────────────────────────────────────────────────────
# Bullseye (jalur tflite-runtime dibangun di atas ABI numpy 1.x) → numpy<2.
# Python 3.11+ → numpy modern; pip resolver memilih versi yang cocok dengan TF.
numpy>=1.23,<2.0 ; python_version < "3.11"
numpy>=1.26 ; python_version >= "3.11"
Pillow>=9.0

# ── Inferensi ML (bccare_ml.py): kode otomatis memilih jalur yang ada ───────
#
# Jalur A — Bullseye (Python < 3.11): TFLite Runtime (ringan ~5 MB).
tflite-runtime>=2.10 ; python_version < "3.11"

# Jalur B — Python >= 3.11: LiteRT (penerus tflite-runtime). Memakai numpy
# sistem (apt) — tidak menimpanya. Terverifikasi di Pi: ai-edge-litert 2.3.0.
ai-edge-litert>=2.1 ; python_version >= "3.11"

# memasangnya secara best-effort sebagai langkah terpisah. Contoh manual:
#   pip install PyBluez
#   pip install RPi.GPIO ; platform_machine == "aarch64"
